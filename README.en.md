# StyleDeck

[中文](README.md) · [User guide](docs/en.html?lang=en)

An independent companion for Capture One workflows. Compare installed styles side by side, shortlist looks, inspect and adjust previews, then send selected candidates to Capture One for further work.

## Version and download

**0.4.8 / build 37, Apple Silicon (arm64)** is being prepared for release. Public downloads are not enabled yet.

The installer is Developer ID signed and Apple notarized. Notarization is a distribution security check, not Capture One endorsement or a rights clearance.

## Requirements and installation

- Apple Silicon Mac; Intel is not supported by this installer.
- Declared minimum: macOS 14. Physical testing on macOS 14/15 and clean-Mac offline first launch remain pending.
- Capture One integration requires a separately installed, properly licensed copy of Capture One and legally obtained styles.
- Open the DMG, drag StyleDeck to Applications, and launch it from Applications.
- Allow StyleDeck to control Capture One when prompted. Review System Settings → Privacy & Security → Automation if previously denied.

## Features and boundaries

Open Capture One sessions or import photos; compare .costyle styles; shortlist, favorite, rate and label candidates; inspect enlarged views; save projects; send candidates to a target Capture One session; export JPEG / PNG. The application supports Simplified Chinese, Traditional Chinese and English.

Compatibility depends on photo format, camera, active style parameters and resources. Unsupported or omitted items are reported in the interface. Previews are not guaranteed to be pixel-identical to Capture One output. Test important workflows with copies.

Sent status confirms execution, saving and required target identity, style and marking checks. It does not certify equality of every adjustment value or rendered pixel.
