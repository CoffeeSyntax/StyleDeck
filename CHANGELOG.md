# 更新记录 / Changelog

## 0.4.8 — build 37

### 中文

- Capture One 推送以命令执行、保存及必要身份、预设和标记检查为准，避免调色数值读回差异造成误报。
- 优化候选勾选时的后台保存与恢复，合并排队保存，减少界面等待。
- 原有完整项目仍可打开，显式保存与另存保留完整可迁移项目。
- 渲染算子与 0.4.7 保持一致；arm64 安装包已完成 Developer ID 签名与 Apple 公证。

### English

- Confirm Capture One sends through command execution, saving and required identity, style and marking checks, avoiding false failures from adjustment readback differences.
- Improve background saving and recovery when selecting candidates, coalescing queued saves to reduce interface stalls.
- Continue to open existing complete projects; explicit Save and Save As retain complete, portable project bundles.
- Rendering operators are unchanged from 0.4.7. The arm64 installer is Developer ID signed and Apple notarized.
